# Chrono VMA eau

Chronométrage multi-athlètes pour le test VMA 5x200 m en natation artistique (send-off 4:00, RPE 2-4-6-8-10).

App : https://sdeguire.github.io/chrono-vma-eau/

- Split 100 m et temps final par couloir, jusqu'à 10 couloirs
- Cycle de send-off avec départ auto et alertes
- Fréquence de bras, courbe de vitesse, archives locales, export CSV
- Fonctionne hors ligne une fois ouverte; s'installe sur l'écran d'accueil (Partager > Sur l'écran d'accueil)

Les résultats restent sur l'appareil (stockage local du navigateur). Exporter le CSV après chaque séance.
